# Заметки

Небольшое веб-приложение для заметок: FastAPI, SQLite и шаблоны Jinja2.
Заметки можно создавать, редактировать и удалять.

Это демо-проект к видео про BMAD Method. Первый коммит это приложение до BMAD,
дальше по истории коммитов видно, как шла работа с BMAD в Claude Code: установка,
задача на одну сессию и эпик со входом через GitHub. Документы BMAD (планы,
спецификация, тикеты, ретроспектива) лежат в `_bmad-output/`.

## Запуск

```bash
uv sync
uv run python seed.py          # тестовые заметки
uv run uvicorn app.main:app --reload
```

Приложение откроется на http://127.0.0.1:8000.

## Тесты

```bash
uv run pytest
```

## Устройство

- `app/main.py`: маршруты
- `app/db.py`: работа с базой SQLite (путь задаёт `NOTES_DB`, по умолчанию `notes.db`)
- `app/templates/`: страницы
- `seed.py`: заполняет базу тестовыми заметками
